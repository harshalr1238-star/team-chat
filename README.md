# TeamSpace – React Chat Application

TeamSpace is a responsive team chat application built using React and Vite. It provides a simple interface for sending messages and interacting with team members.

## Features

- Send and display chat messages.
- Assign messages to team members.
- Like and unlike messages.
- Display the number of likes on each message.
- Emoji picker.
- @mention support.
- Responsive user interface.

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your computer.

### Installation

Clone the repository and navigate to the project directory.

Install the dependencies:

```bash
npm install
```

### Run the Application

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Build for Production

Run the following command:

```bash
npm run build
```

The production build will be generated in the `dist` directory.
